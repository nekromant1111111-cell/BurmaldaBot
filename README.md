# 🤖 Telegram AI Bot (бесплатно!)

Умный Telegram-бот на базе **Google Gemini** (бесплатно) с поддержкой поиска в интернете.

## ✨ Возможности

- 🧠 Общение с AI (Gemini 2.5 Flash) — **бесплатно**
- 🌐 Поиск в интернете (DuckDuckGo)
- 📄 Чтение веб-страниц по ссылкам
- 💬 Помнит историю диалога (~20 сообщений)
- ☁️ Работает 24/7 на Render.com

## 🛠 Что нужно сделать

### 1. Создать бота в Telegram
Найди **[@BotFather](https://t.me/BotFather)** и выполни:
```
/newbot
```
Придумай название и username (заканчивается на `bot`). Сохрани **токен**.

### 2. Получить бесплатный ключ Gemini
1. Зайди на **https://aistudio.google.com/apikey**
2. Нажми **"Create API Key"**
3. Скопируй ключ (начинается с `AIza...`)

Всё, **платить нигде не надо** — у Gemini бесплатный тариф навсегда.

### 3. Настроить и запустить
```bash
# 1. Копируешь файл настроек
copy .env.example .env

# 2. Открываешь .env в блокноте и вставляешь свои ключи
notepad .env

# 3. Запускаешь бота
.venv\Scripts\python.exe bot.py
```

### 4. Задеплоить на Render (24/7)
Смотри инструкцию в `.env.example` и README выше.

## 📁 Файлы проекта

| Файл | Зачем |
|---|---|
| `bot.py` | Точка входа — запуск бота |
| `config.py` | Настройки из .env |
| `app/handlers/start.py` | Команды /start, /help, /clear |
| `app/handlers/ai_chat.py` | Обработка сообщений |
| `app/services/ai_service.py` | Тут живёт AI (Gemini) |
| `.env` | Твои ключи (не коммить!) |

## 📝 Команды бота

- `/start` — приветствие
- `/help` — справка
- `/clear` — сбросить историю
- *Просто текст* — общение с AI
- *Ссылка* — прочитаю страницу
- *"Найди ..."* — поищу в интернете
